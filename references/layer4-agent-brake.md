# L0/L4 · 合规刹车（让守规矩的 AI agent 自己停手）

目标：在你自己的产物里立一块"此地有主、禁止逆向"的清晰牌子，让**守规矩**的 AI agent 读到后自己判断"未授权"并中止。

## 原理
REA、reverse-skill 都跑在 Claude / GPT 这类带合规判断的大模型上。你不是去攻击它，而是让它**读到你的声明后，自己得出"不该继续"的结论**。reverse-skill 自己的规则里都写了"动手前先确认是否授权"——你把"未授权"这个信号明确摆在它面前。

## 做法（全是立牌子，不设陷阱）
1. **规范的版权 / 许可证头**：在源码、二进制资源、APK、JS bundle 里嵌入清晰可读的：
   - 著作权人、项目名
   - "专有软件，用户协议禁止逆向工程 / 反编译 / 复刻"
   - 适用法律提示（DMCA §1201 / 当地法）
2. **完整性签名标识**：让它判断成"这是有主、受保护的东西"，而非"随便可拆的练习目标"。
3. **检测到逆向环境时的许可证告知**（配合 L3）：弹一条"本软件禁止逆向，相关行为可能违约/违法"的提示，并**记录日志作为维权证据**。这是提醒 + 取证。

## ⚠️ 必须让用户知道的真相
- **这一层只筛得掉守规矩的人。** reverse-skill 内置"解除安全审查 / agent 服从性"垫片，铁了心的人直接跳过你的声明。
- **所以 L0 绝不能单独用。** 它是第 0 层筛子，真正的拦截靠 L1–L4（难拆、拆了没用、服务端吊销）。
- **只告知，不恐吓**：可以写"禁止逆向、可能违法"，**不可以**伪造"你已违法/已报警"或自动发起虚假举报——那本身可能构成诬告/欺诈。真追责走律师和真实证据（见 L5）。

## 验收
- [ ] 产物内有清晰的版权/许可证/禁止逆向声明
- [ ] 文案是"告知+取证"，没有伪造恐吓
- [ ] 已明确告诉用户这层对不守规矩者无效，不能单独依赖
